四个各自独立的 App，不是四个皮肤。点哪张脸进哪个仓库。

薄肌、太对了、好事三个同时开着会互相接话，凑成一段捧哏；第四个是别人做的，还没接进这套联动。

## 装

先装一个就行。这三个都装，它们才会互相接话。

1. 从 [Releases](https://github.com/Ganzhe2028/FengGe-Desktop-Pet/releases/latest) 下载最新的 `.dmg`
2. 双击打开，把 app 拖进「应用程序」
3. 第一次打开会弹「无法验证开发者」：右键 → 打开。这只是因为没买苹果签名，不是有毒

不确定自己这台算不算 Apple Silicon：左上角苹果图标 → 关于本机，芯片写 `Apple M` 开头的就是。

11 句原声，一轮播完再重来，不会连着重复同一句。

还装不上、想自己编译、想换声音换脸：[技术文档](TECHNICAL.md)

## 拿去做你自己的

代码 MIT。换脸、换声音、加人、做一个你自己的热梗桌宠，都随便改。Windows 版还没有，欢迎有人做一套。

做出来发到抖音、B站、小红书，带上 `#桌宠接话`，互相 @ 起来。这一组越多人做越好玩。

已经有人做出来了：[Q弹🉐皮炎克劳德](https://github.com/aurelius358/JellyPet)。

想要哪个角色、装不上、有别的想法，开个 [issue](https://github.com/Ganzhe2028/FengGe-Desktop-Pet/issues)；在抖音评论里说也行，两边我都会看。
